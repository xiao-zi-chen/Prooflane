使用说明

可以连接执行节点，也可以导出执行包交给测试者。

准备应用文件

Windows 接收 EXE、MSI、ZIP；macOS 接收包含 APP 的 ZIP、DMG、PKG；Linux 接收 AppImage、ZIP、tar.gz。同一份 Windows EXE 不会被当作 macOS 或 Linux 程序执行。

移动端 Android / iOS 尚未接入，不展示为已支持。

选择执行方式

测试者可以在“执行策略”中下载执行包，在自己的电脑运行后回传结果。需要持续测试时，再接入对应平台的在线节点。

macOS 和 Linux 适配器尚待实机验证。在线任务没有可用节点时会等待；独立执行包的结果需人工复核，不会自动写回控制台。

填写验收步骤

配置 3–5 步共同验收场景，为其他平台上传对应包。步骤名称和动作保持一致，窗口标题、控件名称、控件 ID 和预期文本可以分别配置。

对照页逐行显示各平台结果，能区分待执行、执行失败、检查通过和人工待复核。任务取消或节点失联会保留已知证据。

查看结果与复测

对照页可以复制跨平台反馈，单次运行可下载截图、录像、日志和 JSON 报告。反馈保留平台、架构、安装包哈希、操作步骤及证据索引。

真实客户的构建仍需在可销毁或可恢复快照的专用环境运行；进程管理、节点凭据和任务目录不等于多租户安全隔离。
