## 文档约定

- “已验证”需要说明构建、系统、场景和证据范围；“已实现”只说明代码存在。
- 命令默认从项目根目录执行。执行包里的命令从解压目录执行。
- `artifacts/` 是本地验证产物，不随源码分发。公开文档不能依赖它才能读懂。
- 更新功能时同时更新对应文档；新增文档在本目录登记。页面名称以当前界面为准。
- 根目录和 `docs/` 下的正式文档均有中文页与 `.en.md` 英文对应页，两者一起更新并保留切换链接。

界面目前使用中文。英文指南会标出对应中文按钮；任务名称、窗口标题和断言文本按应用方提供的原值使用。
