# 发布检查

**简体中文** · [English](releasing.en.md)

此清单供维护者准备发布使用。勾选表示该次发布已核对，不表示项目当前已经完成发布。

## 确定范围

- [ ] 权利人已确定许可证，并加入实际 `LICENSE` 文件。
- [ ] 有可追溯的 Git 提交和版本标签，CHANGELOG 对应实际改动。
- [ ] README、界面标识和发布说明使用一致的版本与支持范围。
- [ ] 已配置维护联系与安全报告渠道；未配置的服务不写成已提供。

## 验证

- [ ] 从干净检出安装依赖并启动控制台，记录 Python、系统和依赖版本。
- [ ] 该提交的代码测试、文档检查和前端语法检查通过。
- [ ] 受影响的平台完成必要的 GUI 验证；没有运行的平台保留“未验证”。
- [ ] 导出的说明包、绑定执行包及其 README 可用，未包含其他任务或本地凭据。
- [ ] 文档截图与当前界面一致，链接和示例路径可以从检出目录打开。
- [ ] 中英文文档及执行包说明描述相同的行为与限制。

## 分发内容

- [ ] 排除运行数据、客户构建、凭据、虚拟环境和本地调查。
- [ ] 若提供构建产物，写明目标平台、架构、安装方法和 SHA-256。
- [ ] 记录已知限制、升级方式和回退方式。数据目录尚无迁移工具，升级前应停服备份并验证恢复。
- [ ] 发布说明区分已实现功能、实际验收结果和后续计划。

当前仓库配置的 CI 检查不能代替完整桌面验收。发布记录应给出复现命令和经过脱敏的证据；本地 `artifacts/` 不会自动成为公开证据。
