## 尚未覆盖

- macOS / Linux 目标桌面的实际控件操作、窗口采集和安装。
- 第三方应用、Electron / Qt / 自绘界面及完整的系统版本、DPI 和架构矩阵。
- 跨物理主机连接、真实客户试点和实际付费需求。
- 所有 COM、GPU 或系统安装服务死锁；当前取消与超时机制不等于覆盖全部故障。
- 人为触发原生系统崩溃转储；退出码 42 的样本不代表系统崩溃采集验证。
- 多租户、公网账户、虚拟机生命周期和数据自动清理，这些功能尚未实现。
